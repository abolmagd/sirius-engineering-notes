# Exam plans and progress

## Plan definition

An exam plan connects a date with a normalized curriculum scope. The scope can contain multiple modules and subjects without depending on the wording or visual order of a dashboard control.

Plans are created and edited through authorized administration. Student access remains read-only except for the progress generated by normal answers.

## Matching questions to a plan

A question contributes only when it is inside the student's active year and matches one of the plan's normalized selections. Stable question identifiers are used for progress; renaming a display label does not create a second solved item.

## Progress model

The plan tracks unique question outcomes and daily activity. Re-answering the same question can improve its saved result and attempt statistics, but it does not inflate unique coverage.

```text
on a new committed answer:
  verify that the question matches the active plan
  record or update the question outcome
  increment today's activity once for the new answering event
  recompute the student's plan progress summary
```

The home screen can then show the next target, answered coverage, and the pace implied by the remaining time.

## Time handling

Exam dates are interpreted with an explicit time zone and serialized consistently. The countdown distinguishes future, active, and completed plans. Tests cover daylight and date-boundary behavior so “today” is not accidentally calculated in the server's unrelated time zone.

## Data integrity

Plan writes, question-progress updates, and daily counters are server-authorized. The browser may display an optimistic update, but it does not own the final scope or totals. Database migrations are additive and designed to be safe to re-run during deployment.

## Failure behavior

If plan data is temporarily unavailable, ordinary practice still works. The planner shows a recoverable loading or empty state rather than blocking question sessions. Progress synchronization retries through the same bounded study-data mechanisms used elsewhere.

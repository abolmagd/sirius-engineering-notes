# Question-bank and content pipeline

## Content model

A question contains a stable id, academic scope, chapter, prompt, options, answer metadata, explanation, optional source labels, and optional image references. A shared stimulus stores the case text or image used by several ordered questions.

Stable identifiers separate content identity from visible wording. This allows a typo correction without losing bookmarks or progress.

## Loading strategy

The browser first receives compact startup information, then loads the question snapshot for the student's authorized scope. Answer-key data is requested only for questions required by a session. Large question banks are cached and versioned so unchanged data is not downloaded repeatedly.

Stimulus data is hydrated separately and joined by identifier. Missing or deleted questions are skipped during session restoration rather than crashing the session.

## Sources and filters

Source labels are optional and may contain multiple values. The dashboard derives the available source choices from the currently selected curriculum. Custom filtering matches any selected source; “all” and “none” are explicit states so saved sessions remain predictable.

## Images

Uploads are validated for size, type, and role. Storage paths are generated by the application instead of trusting a user's filename. Dynamic uploads live outside the Git-deployed document tree and are served through a controlled path. Referenced files are removed only after database references are gone.

## Editorial operations

Authorized editors can create and revise scientific content without receiving owner-level access to users or system settings. Bulk deletion uses explicit filters, typed confirmation, bounded batches, and a recycle period. Recovery and final file cleanup are separate operations.

Every material admin action records an audit event. Public student responses expose question content, not admin identity or internal recovery metadata.

## Import quality

Imports validate required fields, preserve text-only stimuli, normalize sources, and check grouped ordering. Automated tests cover field mapping in both directions, optional sources, shared captions, image relationships, deletion recovery, and exact year scoping.

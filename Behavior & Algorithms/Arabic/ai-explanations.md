# الشرح المدعوم بالمصادر

## الهدف

شرح الذكاء الاصطناعي طبقة مساعدة اختيارية لفهم السؤال. لا يستبدل مفتاح الإجابة المحفوظ، ولا يحدد الدرجة، ولا يغير صحة إجابة الطالب.

## ربط الشرح بالمصدر

يرفع أو يسجل المسؤولون مواد تعليمية معتمدة. تُستخرج منها مقاطع قابلة للبحث وتُبنى فهرسة خاصة. عند طلب الشرح، يختار الاسترجاع المقاطع المرتبطة ثم يرسلها مع سياق السؤال إلى نموذج التوليد.

```text
سياق السؤال
  -> استرجاع مقاطع تعليمية معتمدة
  -> بناء prompt محدود بلا هوية الطالب
  -> توليد الشرح
  -> التحقق والحفظ مع بيانات المصدر
  -> إرجاع projection آمن للواجهة
```

الطلب لا يحتاج اسم الطالب أو بريده؛ يركز على السؤال والاختيارات والإجابة المتوقعة والنص المصدر ذي الصلة.

## السلامة والتكلفة

التوليد له حدود لكل مستخدم وللموقع، ومهل زمنية وفحص لحالة النموذج وقياس للاستخدام. الحدود التشغيلية الدقيقة لا تُنشر. إذا تعذر التوليد تظهر حالة قابلة لإعادة المحاولة، ويظل الشرح التحريري متاحًا إن وُجد.

ملفات المصادر والفهارس إدارية خاصة. لا يستطيع العميل العام تصفح مكتبة المصادر أو اختيار مسارات عشوائية على الخادم.

## المراجعة والخصوصية

يمكن الإبلاغ عن النص المولد أو اقتراح تعديله. يراجع المحرر العلمي المحتوى دون امتلاك صلاحيات إدارة المستخدمين. الإصدارات تحفظ أثر التصحيح بدل تغيير هوية السؤال بصمت.

مزود الذكاء الاصطناعي يستقبل أقل محتوى لازم للتوليد فقط. لا تُرسل له كلمات المرور أو الهاشات أو الرسائل الخاصة أو حقول الاتصال بالحساب.

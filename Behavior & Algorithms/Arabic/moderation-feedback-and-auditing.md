# البلاغات والمراجعة وسجل التدقيق

## Feedback الطالب

يمكن للطالب الإبلاغ عن سؤال أو اقتراح تصحيح للشرح أو إرسال ملاحظة عامة. لقطة الشاشة اختيارية ولا ترفع إلا بعد موافقة المستخدم. الواجهة تنبه إلى عدم تضمين كلمات مرور أو رموز استعادة أو محادثات خاصة أو بيانات شخص آخر.

البلاغ المجهول يظهر كـAnonymous، ولا يُستخدم المعرف الداخلي الخام بدل اسم عرض.

## صناديق المراجعة

تُفصل البلاغات واقتراحات الشرح وطلبات الاستعادة والـfeedback في قوائم مخصصة. يستطيع المحرر العلمي مراجعة المحتوى دون الوصول إلى إدارة المستخدمين أو إعدادات المالك.

تُحمّل القوائم metadata صغيرة أولًا، ولا تُفتح البيانات الكبيرة أو الصور إلا عند فتح التفاصيل المطلوبة.

## سجل التدقيق والحذف

العمليات الإدارية الحساسة تنشئ سجلًا يتضمن دور المنفذ ونوع العملية والهدف والوقت وتفاصيل محدودة. الوصول للسجل مقيد بالمالك، ولا يجب أن يحتوي كلمات مرور أو توكنات أو معرفات جلسات كاملة أو بيانات شخصية لا حاجة لها.

حذف السؤال قابل للاسترجاع خلال فترة محددة، وتبقى الصورة حتى تزول كل مراجعها. الاسترجاع والتنظيف النهائي عمليتان منفصلتان ومصرح بهما ومسجلتان.

## التحقق

المسارات العامة للبلاغات والرفع تستخدم حجمًا وأنواع ملفات محددة وفحص أصل وضوابط إساءة. النص يعرض كنص أو بعد escaping. الحدود الإنتاجية الدقيقة لا تُنشر.

# تسجيل الدخول واستعادة الحساب

## حد المصادقة

المصادقة الإنتاجية مملوكة للخادم. يرسل المتصفح بيانات الدخول عبر HTTPS ويستقبل تمثيل جلسة مناسبًا للعميل. هاشات كلمات المرور ومفاتيح التوقيع وبيانات قاعدة البيانات لا تنتمي إلى ملفات الواجهة أو Git.

كلمات المرور تُخزن بخوارزمية بطيئة مخصصة لكلمات المرور يوفرها runtime الخادم، وليست بهاش عام سريع، ولا تُكتب في السجلات كنص صريح.

## الجلسات

الدخول الناجح ينشئ جلسة جديدة. تُضبط الكوكيز ورؤوس الاستجابة لتقليل وصول JavaScript ومخاطر الطلبات من المواقع الأخرى وكاش الاستجابات الحساسة. الخادم يتحقق من الصلاحية في كل عملية محمية، والزر المخفي لا يعتبر حماية.

## استعادة كلمة المرور

الاستعادة الذاتية تستخدم ردًا عامًا لا يؤكد هل البريد مرتبط بحساب. يرسل رابط مؤقت أحادي الاستخدام عبر مسار البريد المضبوط. صفحة الاستعادة تتحقق من الرابط وتطلب كلمة مرور جديدة.

قد ينفذ المسؤول عملية استعادة منفصلة عند الحاجة، وتكون مسجلة في سجل التدقيق وقد تُلزم الطالب بتغيير الاعتماد المؤقت. لا توجد كلمات مرور مشتركة ثابتة.

بعد تغيير حساس أو reset تُجدد حالة المصادقة حتى لا تستمر جلسة قديمة بلا نهاية. حالة الحساب على الخادم هي المصدر النهائي لقرار إجبار التغيير.

## حماية المستودع

الملف المتعقب هو نموذج إعدادات يحتوي placeholders فقط. الإعداد الفعلي متجاهل في Git ومحمي على الخادم. الفحوصات الآلية ترفض المفاتيح الخاصة وصيغ التوكن والهاشات وتصديرات قاعدة البيانات وأسماء الاستثناءات.
